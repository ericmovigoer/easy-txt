# Triage 标签

相关技能使用五种规范的 triage 角色。此文件把这些角色映射到本仓库 issue tracker 使用的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签        | 含义                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 需要维护者评估此 issue     |
| `needs-info`               | `needs-info`      | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent` | 信息完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要人工实现               |
| `wontfix`                  | `wontfix`         | 不会处理                   |

当技能提及某个角色时，使用此表中对应的标签字符串。

如需匹配实际采用的标签词汇，可编辑右侧列。
