# 自有代码使用 C，允许非 C 的第三方组件

状态：已接受，依据需求访谈第一轮 Q3 及用户“全部按建议”的确认。

本项目重视轻量、性能和可维护性，自有代码全部使用 C，但允许通过 C 可调用接口使用内部由其他语言实现的第三方组件。相较于要求所有第三方源码也必须是 C，这一边界保留了复用成熟编辑组件的可能，减少自行实现基础编辑能力的工作；代价是构建和分发可能包含非 C 实现的依赖，因此不能将完整程序描述为所有源码均为纯 C。本决定不单独锁定组件，后续确认的候选路线与模块责任见 [ADR-0002](0002-editor-ownership-and-platform-isolation.md)；具体依赖仍须评估功能、性能、许可证和分发影响。
