# 06: 基础编辑与定位操作

**What to build:** 用户可以通过菜单和键盘完成剪贴板编辑、跳转行、整行缩进与自动缩进，并选择 Tab 行为和自动换行。

**Blocked by:** 01：UTF-8 单文档编辑闭环。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 13、18、19、20、21、65；验收场景 A02、A09；需求依据 Q9、Q16。

## 验收标准

- [ ] 剪切、复制、粘贴和全选通过菜单及常用快捷键可用，实际剪贴板中的中英文和非 BMP 文本可正确往返。
- [ ] 跳转行能够定位到指定有效行；无效输入或超出文档范围时给出可理解的处理结果。
- [ ] 整行增加与减少缩进适用于当前行和多行选区；自动缩进延续上一行，且相关修改可撤销。
- [ ] 默认 Tab 宽度为 4，Tab 键插入空格；用户可调整宽度并改用制表符，显示宽度与实际插入字符的行为一致。
- [ ] 自动换行默认关闭，用户可以开启或关闭；仅改变显示方式，不写入新的换行符或改变保存编码。
- [ ] 这些操作保留文本与未保存修改状态的一致性，不因定位、选择或显示选项本身伪造文本修改。

## 验证方式

应用层命令验证文本、选区、定位、撤销与未保存修改；用实际 Windows 程序验证快捷键、系统剪贴板和自动换行显示。设置持久化在 17 验证。

## 范围与衔接

资源不足和超大粘贴的保护由 13 验证；此工单先交付常规规模的完整操作。
