# 05: 只读文件与外部变更处理

**What to build:** 用户可以查看只读文件并另存为；当文件被其他程序修改或删除时得到明确提示，并能保留本地编辑后自行处理冲突。

**Blocked by:** 04：按指定编码查看与显式格式转换。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 49、50、51；验收场景 A06；需求依据 Q13、Q14。

## 验收标准

- [ ] 只读文件可以正常查看，另存为可写的新文件可成功；不能覆盖目标时明确报告，不把失败保存标成功。
- [ ] 文件被外部修改或删除时有明确提示，用户可理解磁盘内容与当前文档可能不一致。
- [ ] 存在本地未保存修改时不自动重新读取或覆盖；取消处理、选择保留当前内容和明确处理后继续均不会静默丢失编辑。
- [ ] 选择重新读取时复用未保存修改保护与严格读取行为；读取失败保留原内存内容，成功读取结束旧历史。
- [ ] 保存前识别外部变更冲突并交由用户处理，取消或失败不覆盖用户尚未同意处理的变化。
- [ ] 通过平台边界控制外部修改、删除、权限错误和保存冲突；同时以真实文件验证外部修改与删除的可观察结果。
- [ ] 保存失败后仍可重试或另存为；成功保存遵守保存临时文件策略，不产生常驻备份。

## 验证方式

应用层命令与受控平台事件验证确定性异常，真实临时文件集成验证外部变更；实际 UI 验证只读、冲突和错误提示。断言文档文本、磁盘内容、操作结果与未保存修改。
