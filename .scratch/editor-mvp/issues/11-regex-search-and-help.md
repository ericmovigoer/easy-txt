# 11: 正则查找与语法帮助

**What to build:** 用户可以使用正则表达式搜索当前文档或选区，理解表达式错误，并查阅与实际组件一致的正则语法帮助；耗时正则仍可取消。

**Blocked by:** 10：可取消的普通文本查找。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 31、32、33、35、36、37；验收场景 A04；需求依据 Q11、Q20。

## 验收标准

- [ ] 在现有查找流程中提供正则模式，支持当前文档与选区、上一个和下一个匹配，相关大小写及整词选项的行为与界面说明一致。
- [ ] 无效正则明确报错，不以无匹配冒充语法错误，且不修改文档文本或未保存修改状态。
- [ ] 帮助说明实际采用的正则语法、支持范围与限制，并与所记录的候选组件版本保持一致。
- [ ] 包含零长度匹配和可能耗时的表达式样本；前后定位不会无限循环，耗时计算可取消且不会长时间阻塞输入。
- [ ] 编辑文档或改变查询后，旧正则结果不能覆盖新状态；取消后继续输入和重新查找正常。
- [ ] 如需要独立正则组件，通过真实行为和测量验证 C 可调用、运行依赖与便携分发约束；不能因为候选组件缺少接口而放弃取消或响应性要求。
- [ ] 记录组件、样本、取消操作、响应观察与未通过项，为最终依赖采用提供证据。

## 验证方式

应用层命令连接真实正则和编辑组件，验证正常匹配、无效表达式、零长度匹配、取消及过期结果；实际程序补充耗时表达式期间的输入响应验收。

## 范围与衔接

正则能力仍属于候选路线；语法帮助应描述已验证行为，不预先承诺未经验证的引擎特性。
