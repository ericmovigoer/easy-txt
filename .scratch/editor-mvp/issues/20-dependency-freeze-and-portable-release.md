# 20: 依赖定版与便携发布验收

**What to build:** 用户获得可在 Windows 10/11 x64 标准用户环境解压即用的中文便携运行包；维护者获得经过功能、性能和分发验证的依赖定版与可复现构建记录。

**Blocked by:** 19：性能目标验证与瓶颈修复。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 1、2、52、71、73、74、75、76、77、78；验收场景 A01、A02、A03、A04、A05、A06、A07、A08、A09、A10、A11、A12；需求依据 Q3、Q7、Q8、Q21、Q22。

## 验收标准

- [ ] 逐项核对候选路线采用证据：C 调用、全部首批语言、中文输入法与高 DPI、各编码往返和混合换行、100 MB 与长行、撤销资源保护、可取消搜索及保存失败时内容保留。
- [ ] 仅在采用条件实际通过后固定最终依赖、版本、构建方式和必要接口；依赖变化影响既有结果时重新验证相关场景，不用候选组件的功能声明代替实测。
- [ ] 提供可复现的构建说明和版本记录，自有代码继续使用 C；允许可由 C 调用的非 C 第三方组件，平台调用集中隔离，不长期维护两套文本和撤销栈。
- [ ] 生成 Windows x64 便携运行压缩包，运行所需依赖及许可说明完整；运行包不计入源码、测试数据或调试符号，这些可另行分发。
- [ ] 在 Windows 10 和 Windows 11 x64 标准用户环境分别验证解压即可离线运行，无需额外安装运行库；未能实际执行的平台保留未验收状态。
- [ ] 检查完整运行压缩包不超过 20 MB 的体积目标，记录实际大小与依赖构成；未达到目标时明确报告原因与方案，不把目标当成已通过。
- [ ] 确认程序不主动访问互联网，没有遥测、更新检查或外部在线服务；主动选择网络文件属于文件访问，其错误与超时结果按 18 验收。
- [ ] 检查运行与退出不产生常驻备份、文件历史、会话恢复、文档内容或搜索/光标历史持久化；用户偏好与短暂保存临时文件仍符合规格。
- [ ] 汇总 A01～A12 的实际执行结果和证据，复验跨工单组合：仅格式变化触发关闭提示、多文档重新读取历史、大文件模式下按指定编码查看、主题下各类高亮、加载与单实例打开、偏好异常与退出。
- [ ] 对最终运行包复核性能证据与构建一致性；构建或依赖改变时重测受影响指标，未通过项和未执行项明确列出，不能仅因工单已创建就标验收完成。

## 验证方式

运行最终便携包完成真实 Windows 10/11 UI、离线、标准用户及系统集成验收，复用应用层命令回归和 19 的性能方法；检查发布内容、许可、配置与文件访问结果，记录可复现证据。

## 范围与衔接

本工单通过 19 间接等待全部前置功能。交付范围为便携运行包与验证记录，不扩展安装包、文件关联、Linux UI、自动更新或外部在线服务。
