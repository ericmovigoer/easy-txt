# 07: 代码阅读与语言支持

**What to build:** 用户打开代码或配置文件后可以获得对应语言的语法高亮、结构折叠和阅读辅助，也能手动指定语言或使用纯文本模式。

**Blocked by:** 01：UTF-8 单文档编辑闭环。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 18、22、23、24、25、26；验收场景 A02；需求依据 Q1、Q9、Q10。

## 验收标准

- [ ] 逐项覆盖 C、C++、Python、JavaScript、TypeScript、JSON、INI、YAML、Markdown、HTML、XML、CSS、PowerShell、批处理的语法高亮；每种语言都有可验证的代表样本。
- [ ] 按扩展名选择语言，允许用户手动覆盖；未知扩展名按纯文本显示，手动选择对当前文档生效。
- [ ] 行号、当前行高亮和括号匹配可见且随编辑及光标位置更新，不改变文档文本。
- [ ] 语言允许的折叠可展开和收起，文档初次打开时全部展开；逐种语言记录折叠是否适用及验证结果。
- [ ] 切换语言或显示功能不改变保存编码、BOM、换行符或未保存修改状态。
- [ ] 在实际候选组件上验证 C 调用与各语言行为，记录组件版本、样本及未通过项；不能仅凭组件声称支持就标为通过。

## 验证方式

应用层命令验证语言选择及可观察文档状态，真实 Windows UI 验证全部首批语言的显示和折叠；记录可复现的样本与操作。

## 范围与衔接

本工单不包含项目级语义分析、索引或跨文件功能。大文件模式中的默认关闭与逐项恢复由 15 接入。
