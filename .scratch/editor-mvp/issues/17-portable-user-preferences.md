# 17: 用户偏好持久化

**What to build:** 用户关闭并重新启动便携程序后，可以恢复个人显示与编辑偏好；配置不能写入或损坏时得到提示，并继续使用本次设置或默认值。

**Blocked by:** 06：基础编辑与定位操作；08：中文输入与显示设置。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 52、66、67、68、69；验收场景 A10；需求依据 Q6、Q17。

## 验收标准

- [ ] 在程序目录的配置文件保存字体、字号、主题、窗口大小、Tab 宽度及缩进选项等用户偏好；真实进程重启后恢复已保存的设置。
- [ ] 程序目录不可写时明确提示，当前运行中的设置仍有效，不自动改写到其他位置。
- [ ] 配置损坏时明确提示并采用默认设置，不在读取、后续保存或正常退出时静默覆盖损坏文件。
- [ ] 配置不含文档路径、文档内容、文件历史、搜索历史或光标历史，也不持久化文档集合和会话恢复数据。
- [ ] 重启仅恢复用户偏好，不恢复标签或编辑状态；仍保留关闭时对未保存修改的提示流程。
- [ ] 验证正常写入、目录不可写、损坏内容和缺少配置的行为；缺少配置时使用默认设置而不影响启动。

## 验证方式

通过应用层设置流程、平台受控失败和真实进程重启验证；检查配置内容与实际写入位置，实际 UI 核对恢复结果。仅格式修改等完整关闭组合由 20 复验。

## 范围与衔接

用户偏好与文件历史、会话恢复严格区分。配置异常提示不能通过偷偷改写其他目录或覆盖损坏原件来消除。
