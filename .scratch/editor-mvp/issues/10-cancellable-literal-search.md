# 10: 可取消的普通文本查找

**What to build:** 用户可以在当前文档或选区内执行普通文本查找，按大小写和整词条件定位上一个或下一个匹配，耗时查询可取消且不会长时间阻塞输入。

**Blocked by:** 01：UTF-8 单文档编辑闭环。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 31、32、33、36、37；验收场景 A04；需求依据 Q11、Q20。

## 验收标准

- [ ] 提供当前文档和选区范围，支持普通文本、大小写和整词选项，以及上一个、下一个匹配；不同范围和选项具有明确可验证结果。
- [ ] 查找结果样式清晰可见，查找操作本身不修改文本或未保存修改状态。
- [ ] 耗时查找提供可用的取消入口，取消后停止呈现该任务的新结果，文档仍能继续输入。
- [ ] 计算期间发生编辑后，旧结果不直接覆盖或应用到新内容；更换查询条件后旧任务也不能覆盖新查询结果。
- [ ] 用大文本样本实际验证输入响应和取消，记录候选组件的调用约束、调度方式及行为证据；仅把调用发到其他线程不算验证通过。
- [ ] 处理无匹配、文档边界及空选区等情况，不出现无限循环或破坏当前文档。

## 验证方式

应用层命令验证范围、匹配、定位、取消与过期结果；真实组件和 Windows 程序验证长任务期间输入响应。测试断言最终可见结果，不绑定线程数量或窗口消息调用次数。

## 范围与衔接

正则查找由 11 扩展，替换由 12 扩展；本工单先形成普通文本查找的完整纵向路径，不增加跨文件搜索。
