# 14: 选中文本匹配高亮

**What to build:** 用户选中一段有效文本后，可以看到当前文档中相同字面子串的匹配高亮，并能区分它与主动查找产生的结果。

**Blocked by:** 10：可取消的普通文本查找。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 27、28、29、30；验收场景 A03；需求依据 Q12。

## 验收标准

- [ ] 只在当前文档进行区分大小写的字面子串匹配，不要求整词，不把选区解释为正则。
- [ ] 选中 foo 会匹配 foobar 内的 foo，不匹配 Foo；允许单字符选区。
- [ ] 纯空白或多行选区不触发匹配高亮；改成无效选区时不残留前一个有效选区的结果。
- [ ] 选区稳定约 150 毫秒后更新，快速改变选区时只呈现当前选区的有效结果；取消选区即清除。
- [ ] 匹配高亮样式与 10 的查找结果可区分，两者存在时用户可以理解各自含义。
- [ ] 高亮不改变文本、撤销历史或未保存修改状态；文档变化时旧匹配不会错误标记新内容。

## 验证方式

应用层选择与查找相关命令验证有效选区和匹配结果；实际 Windows UI 验证延迟、清除与两种样式的区别。通过外部可观察效果判断，不绑定计时器或内部消息的实现。

## 范围与衔接

大文件模式中的默认关闭与手动恢复由 15 集成；本工单不把选中文本匹配高亮扩展为代码符号分析。
