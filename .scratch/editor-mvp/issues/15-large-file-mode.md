# 15: 大文件模式

**What to build:** 用户打开较大文件或超长单行时，可以看到大文件模式状态，在减少显示增强功能后继续基础编辑，也能逐项尝试恢复显示功能。

**Blocked by:** 07：代码阅读与语言支持；09：可取消的文件加载；13：超大编辑与资源不足保护；14：选中文本匹配高亮。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 53、54、55；验收场景 A07；需求依据 Q2、Q15、Q20。

## 验收标准

- [ ] 暂定文件达到 20 MB 或单行达到 256 KiB 时进入可见的大文件模式；检查阈值两侧及恰好达到阈值的样本，记录使用的计量口径。
- [ ] 大文件模式默认关闭语法高亮、折叠、自动换行和选中文本匹配高亮；用户可以逐项尝试恢复，界面正确反映当前选择。
- [ ] 大文件模式继续提供基础编辑、撤销、查找与替换及手动编码选择，不能把该模式实现为只读模式。
- [ ] 10 MB 以内普通文件保留完整体验；使用 100 MB、超长单行和单行 JSON 样本验证模式与核心功能。
- [ ] 模式切换及显示功能恢复不改变文本、保存格式或未保存修改；资源保护仍生效，不通过静默清空历史维持运行。
- [ ] 沿用加载进度、取消、完整载入和 256 MiB 上限规则；加载时其他标签可操作，取消不产生可误保存的文档。
- [ ] 允许基于原型实测调整暂定触发阈值，但须记录测量依据；不得借此降低 256 MiB 上限、功能行为或已确认性能目标。

## 验证方式

应用层命令验证模式、基础操作和失败后的文档状态；真实程序检查默认关闭、逐项恢复与长行响应。记录实际候选版本、样本和观察，最终量化性能由 19 验证。

## 范围与衔接

手动编码选择沿用已交付的编码入口；按指定编码重新读取等跨工单组合由 20 集成验收。模式阈值调整与产品要求变更须区分。
