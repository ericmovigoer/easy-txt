# 08: 中文输入与显示设置

**What to build:** 用户可以可靠输入和阅读中文、英文及非 BMP 字符，选择字体、字号和缩放，并在不同 DPI 与浅深主题下使用中文界面。

**Blocked by:** 01：UTF-8 单文档编辑闭环。

**Status:** ready-for-agent

**需求追踪：** 轻量文本编辑器首版规格；用户故事 61、62、63、64、65；验收场景 A09；需求依据 Q7、Q9、Q16。

## 验收标准

- [ ] 默认使用等宽字体和浅色主题，可选择字体、字号与缩放，切换浅色或深色主题；显示设置不修改文档文本。
- [ ] 实际中文输入法的组合输入、候选提交和取消不会丢字、重复输入或损坏光标位置；中英文混排与非 BMP 字符可输入、选择和编辑。
- [ ] 所选字体缺少部分字符时验证字体回退结果，记录使用的字体、样本与可观察限制。
- [ ] 在实际 Windows 高 DPI 环境验证文字、菜单、标签、编辑区、状态栏和对话框的尺寸与可操作性；记录系统缩放和显示环境。
- [ ] 常用操作可以通过键盘完成，切换显示设置后仍能正常输入并操作文档。
- [ ] 记录候选组件版本、输入法、字体与 DPI 验证结果，为最终采用条件提供证据，不把一次普通英文输入等同于中文输入法验收。

## 验证方式

以真实 Windows 程序的输入法、字体选择、主题和 DPI 验收为主；通过应用层状态辅助核对显示设置未修改文本。无法实际执行的环境明确记录为未验收。

## 范围与衔接

设置持久化由 17 交付；后续语言、查找和选中文本匹配高亮与主题的组合在 20 集成验收。
